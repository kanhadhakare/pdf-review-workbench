# PDF Review Workbench

Standalone local tool for PDF-to-fixed-layout-HTML extraction, review, and profile-based learning.

## Workspace
- `apps/api`: Node.js extraction and review API
- `apps/web`: Angular review UI
- `packages/shared`: shared contracts
- `storage`: uploads, jobs, fixes, profiles, models

## Current Status
- Shared contracts created
- API foundation created
- Angular workspace foundation created
- Prototype folders `backend/` and `frontend/` remain untouched for reference

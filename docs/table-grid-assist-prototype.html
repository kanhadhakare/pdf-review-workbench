How User Handles Tables

The system does not guess complex tables from word positions. The user controls the grid, and the tool assigns existing extracted words, equations, and image crops into the confirmed cells.

1
Draw one table box Default output is a clean crop for pixel-perfect result.
2
Choose Semantic Table Only simple/important tables need HTML conversion.
3
Adjust grid lines Drag blue lines, add rows/columns, merge cells later.
4
Assign content by coordinates Words/equations/images inside a cell become that cell’s content.
5
Save confirmed table Final HTML gets real table only after user approves structure.
